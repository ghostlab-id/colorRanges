# Create a Color Range Between Two Colors

Generate a sequence of colors by interpolating between two endpoint
colors. If a single color is supplied, that color is repeated.

## Usage

``` r
create_color_range(color_palette, n, single_color = "middle")
```

## Arguments

- color_palette:

  A character vector containing one or two colors in a format understood
  by [`grDevices::col2rgb()`](https://rdrr.io/r/grDevices/col2rgb.html),
  such as hexadecimal color codes or R color names. With two colors,
  these define the endpoints of the generated range.

- n:

  A positive integer specifying the number of colors to generate.

- single_color:

  Character string defining which color is returned when `n = 1` and two
  endpoint colors are supplied. One of `"middle"` (default), returning
  the color between both endpoints; `"first"`, returning the first
  endpoint; or `"last"`, returning the second endpoint.

## Value

A character vector of length `n` containing hexadecimal color codes.

## Details

When two endpoint colors are supplied, colors are generated by
interpolation between the endpoints using
[`colorspace::mixcolor()`](https://zeileis.codeberg.page/colorspace/reference/mixcolor.html).
Both endpoint colors are included when `n > 1`.

When only one color is supplied, it is repeated `n` times.

When `n = 1` and two endpoint colors are supplied, `single_color`
determines which color represents the range. By default, the midpoint
between both endpoint colors is returned.

## Examples

``` r
# Define a set of colors between two endpoints
create_color_range(c("#2166AC", "#B2182B"), 5)
#> [1] "#2166AC" "#45538C" "#6A3F6C" "#8E2C4B" "#B2182B"

# Assign a color to multiple entries
create_color_range("steelblue", 3)
#> [1] "#4682B4" "#4682B4" "#4682B4"

# Select a single color from a range
create_color_range(c("#2166AC", "#B2182B"), 1)
#> [1] "#6A3F6C"
create_color_range(c("#2166AC", "#B2182B"), 1, single_color = "first")
#> [1] "#2166AC"
create_color_range(c("#2166AC", "#B2182B"), 1, single_color = "last")
#> [1] "#B2182B"
```
